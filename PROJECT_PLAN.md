# NOCPilot Capstone Project Plan

## Problem

Tier 1 NOC analysts often receive alerts without enough context. They must manually check logs, devices, tickets, and escalation steps.

## Solution

NOCPilot provides a dashboard that explains network alerts in plain English and recommends troubleshooting actions.

## Target Users

- NOC analysts
- IT support teams
- Network operations teams
- Junior network technicians

## Main Use Cases

1. View network device health
2. Detect simulated network incidents
3. Explain alert meaning
4. Recommend next troubleshooting steps
5. Generate ticket notes

## MVP Features

- Device dashboard
- Alert generator
- Alert severity
- AI troubleshooting explanation
- Ticket note generation

## Future Improvements

- Real SNMP monitoring
- Syslog ingestion
- Database persistence
- User login
- OpenAI API integration
- ServiceNow/Jira ticket integration
- Email or Teams notifications
